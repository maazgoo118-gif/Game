# TRAP CAM

مشروع مقلب كاميرا يعمل عبر المتصفح، مع شريط تقدم ولوحة خاصة بصاحب المشروع.

## مهم قبل الاستخدام
- المشروع مصمم للمشاركة الواضحة: يشرح للمشارك أن الكاميرا ستلتقط صورة وأن الصورة سترسل إلى صاحب اللعبة، ولا يحدث الإرسال إلا بعد ضغط زر الموافقة.
- لا تستخدمه للتصوير السري أو لإحراج شخص دون رضاه.
- لا ترفع مجلد `uploads` أو ملف `.env` إلى GitHub.
- GitHub Pages يستضيف ملفات ثابتة فقط ولا يشغّل خادم Node.js. لذلك تحتاج إلى استضافة Node.js للخادم، ويمكن وضع الواجهة على نفس الخادم أو استضافتها منفصلة مع إعداد CORS بعناية.

## التشغيل محلياً
1. ثبّت Node.js 20 أو أحدث.
2. انسخ `.env.example` إلى `.env`.
3. غيّر `SESSION_SECRET` إلى قيمة عشوائية طويلة، واختر كلمة مرور قوية في `ADMIN_PASSWORD`.
4. نفّذ:
   ```bash
   npm install
   npm start
   ```
5. افتح `http://localhost:3000`.

الكاميرا تتطلب HTTPS في النشر الفعلي (localhost استثناء للتطوير).

## النشر
انشر المشروع على خدمة تدعم Node.js، واضبط متغيرات البيئة:
- `SESSION_SECRET`
- `ADMIN_PASSWORD`
- `NODE_ENV=production`
- `PUBLIC_BASE_URL` (للتوثيق/الإعدادات المستقبلية)

استخدم قرصاً دائماً (persistent disk) لمجلدي `uploads` و`data`؛ وإلا قد تضيع الصور عند إعادة تشغيل الخدمة. استخدم HTTPS. لا تضع الأسرار داخل ملفات الواجهة أو مستودع GitHub.

## لوحة التحكم
افتح `/admin.html` وسجّل الدخول بكلمة المرور المحددة في `.env`.
الصور محفوظة خارج مجلد `public` ولا يمكن فتحها إلا بعد تسجيل دخول المالك. يمكنك معاينتها، إضافة فلتر وعبارة، تنزيل النسخة المعدلة أو مشاركتها يدوياً، أو حذف الأصل نهائياً.

## ملاحظات أمنية
هذا إصدار أولي مناسب للتجربة. قبل استخدامه مع جمهور واسع، استبدل مخزن الجلسات الافتراضي بمخزن جلسات دائم مثل Redis أو SQLite، وأضف سياسة خصوصية ومدة احتفاظ واضحة ونسخاً احتياطياً مشفراً. لا ترسل الصور تلقائياً إلى أي شخص؛ زر المشاركة يفتح آلية المشاركة التي يتحكم بها صاحب الحساب.
